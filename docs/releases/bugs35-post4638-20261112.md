# November 12 targeted corrections after 4638

Base: 706007c31c8926146c68abd323c645f372a51802 (signed build 4638). Tracking: #454; existing release branch/PR #447.

## Changes

- Close invoices keeps its existing sheet mounted through confirmation and local closure. Successful IDs are removed in place; selection/count/amount and disabled state are recomputed. Repeated taps are blocked during confirmation and commit. Failure stays in the panel. The existing atomic local closure service and background sync are unchanged.
- Payment header and fully-covered summary use Paid/Closed rather than substituting Pending sync/Pending Close. Saved finalization wording distinguishes the retained request from confirmed server posting. Finalization state is read after local overlays, recognizes an exact saved local-to-server document alias, and blocks overlapping previously finalized receipts. A synchronous tap guard prevents concurrent confirmation dialogs. No historical payment inserts, edits, deletes, or automatic finalizations are introduced.
- Meaningful repair text equal to a job title is retained; generic Invoice/number titles remain excluded. Legacy cached invoice descriptions are available to Jobs, and an empty extracted summary cannot overwrite an existing saved work summary.
- Job Details puts the invoice icon/full link on the left and existing Main Mechanic selector on the right; View Tasks remains the one task navigation action. The selector retains its existing assignment/hour editor.
- Service Tasks filters collapse; grouped cards retain expansion and invoice navigation. Some completed tasks plus unfinished tasks means In Progress, including 2/3 = 67%; all completed means Done. Expanded active groups include their completed tasks, with green/blue/orange task indicators. Filters retain existing historical/payroll rules.
- Findings show lifecycle state without per-finding synchronization messages. Findings persistence and synchronization logic are unchanged.
